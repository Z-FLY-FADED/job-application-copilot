# 职投台

一个本地运行的中文智能求职工作台，用于简历画像、岗位匹配、招聘来源检索、投递队列管理和记录导出。

## 功能

- 简历文本分析与技能关键词提取
- 求职目标和自动筛选规则
- 岗位匹配评分及批量导入
- BOSS直聘、智联招聘、前程无忧、猎聘、拉勾等平台入口
- 国聘、国资央企、事业单位和公务员公开招聘入口
- 每日岗位情报合并与去重
- 个性化沟通话术
- 投递前人工确认与 CSV 记录导出
- 本地数据备份

## 使用

Windows 用户双击：

```text
启动投递助手.bat
```

也可以直接使用浏览器打开 `index.html`。

## 数据与隐私

- 简历和求职数据默认保存在浏览器 `localStorage`。
- 工具不会绕过登录、验证码、频率限制或招聘平台规则。
- 对外投递和发送个人信息前保留人工确认。
- 官方招考岗位的报名条件和截止时间以原始公告为准。

## 每日岗位

`daily-jobs.js` 保存每日更新的公开岗位元数据。打开“岗位情报”页面后，可将新岗位去重合并至本地岗位库。

## 文件

- `index.html`：应用界面
- `styles.css`：页面样式
- `app.js`：核心业务逻辑
- `platform-adapters.js`：招聘平台适配器
- `job-sources.js`：招聘与官方公告来源
- `daily-jobs.js`：每日岗位情报

## 许可

本项目仅用于个人求职信息整理和辅助投递。使用者应遵守招聘平台规则及适用法律法规。
