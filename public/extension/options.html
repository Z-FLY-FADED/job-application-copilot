备份与管理

JSON 文件包含个人资料，请妥善保管。普通备份导入会替换资料；增量资料包会合并并跳过重复记录。导入后请检查并保存。

使用方法与支持范围

保存资料后，在招聘申请网页点击插件 → 识别当前页面 → 核对字段 → 填入。支持普通输入框、多行文本、原生下拉框、命名单选组、常见日期格式、开放的 Shadow DOM 和可访问的同源内嵌表单。多段经历可以逐字段指定；建议先在网站中添加所需的经历表格，再重新识别。未适配的自定义联动控件、文件上传、复选、验证码和跨域内嵌表单需手动操作。请核对日期、薪资单位和网站校验结果。
